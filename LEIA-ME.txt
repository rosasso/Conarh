APP KAVUKA — "APARÊNCIA ENGANA" (CONARH)
=========================================
Quiz interativo de background check + captação de leads, 100% offline.
Feito para rodar em tablet, salvando os leads LOCALMENTE no aparelho.

O layout segue o mesmo padrão visual da apresentação em PowerPoint
("APP CONARH.pptx", que está nesta pasta como referência).


COMO O APP CHEGA NO TABLET
--------------------------
O repositório é PRIVADO, e GitHub Pages em repositório privado exige conta
paga. Ou seja: NO MOMENTO NÃO EXISTE LINK NO AR.

O app que está no tablet foi instalado enquanto o repositório esteve público
e roda 100% offline — não depende de link nenhum para funcionar no estande.

PARA PUBLICAR UMA VERSÃO NOVA (ou instalar em outro tablet):

  1. Deixe o repositório público:
        gh repo edit rosasso/Conarh --visibility public --accept-visibility-change-consequences
  2. Espere 1 ou 2 minutos e abra no tablet:
        https://rosasso.github.io/Conarh/
     CUIDADO com o "C" MAIÚSCULO — "/conarh" minúsculo dá 404.
     Abra, FECHE e ABRA DE NOVO (ver o porquê logo abaixo).
  3. Feche de novo:
        gh repo edit rosasso/Conarh --visibility private --accept-visibility-change-consequences

Alternativa sem link: o index.html é um arquivo único e autossuficiente.
Dá para mandar por Drive, e-mail ou cabo e abrir direto no navegador — só
não instala como app nem atualiza sozinho.

O ciclo de edição é sempre:  mexe em src/  →  python3 build.py  →  git push

Se o site parar de atualizar do nada, confira se o arquivo ".nojekyll" ainda
está na raiz. Sem ele o Pages processa tudo com Jekyll, que tenta interpretar
os marcadores {{LOGO}} do src/app.html como código dele e o build QUEBRA.

O app tem "noindex" e um robots.txt bloqueando buscadores — são rostos
realistas com fichas criminais fictícias, serve pro estande e não para
aparecer no Google. NÃO REMOVA, é o que protege a gente nas vezes em que o
repositório precisa ficar público.

Pelo mesmo motivo, o "APP CONARH.pptx" e o "plano-midia-conarh.html" ficam SÓ
no Mac (estão no .gitignore): é material comercial interno.


COMO USAR NO TABLET
-------------------
1. Já está instalado no tablet. Se precisar instalar de novo, siga os passos
   de "COMO O APP CHEGA NO TABLET" lá em cima.
   Dica: use "Adicionar à tela de início" para virar um atalho de tela cheia.
2. Ao publicar uma versão nova, abra o link, FECHE E ABRA DE NOVO. O service
   worker novo se instala em segundo plano e só entra em ação no acesso
   seguinte — olhando só a primeira carga, você ainda vê a versão antiga.
3. Ao tocar em PESQUISAR o app entra em tela cheia automaticamente (kiosk).
4. Deixe o visitante jogar: escolhe a vaga → escolhe o candidato →
   vê os alertas → RESPONDA → preenche o cadastro → tela de "Obrigado".
5. Sem toque por 2 minutos, o app volta sozinho para a tela inicial.

COMO EDITAR O APP
==========================================================================

O "index.html" é o app pronto, com as imagens embutidas (7 MB). NÃO edite ele
direto — ele é GERADO. Quem manda é a pasta "src":

  src/app.html    → o layout, as cores, os textos fixos e o código
  src/jobs.json   → as vagas, os candidatos e os alertas de cada um
  src/img/        → todas as imagens (logo, capivara, máquina, candidatos, ícones)

Depois de mexer em qualquer coisa dentro de "src", rode no Mac:

    cd /Users/sasso/opensquad/apps/conarh
    python3 build.py

Isso regera o "index.html" e já atualiza a versão do cache (senão o tablet
continuaria mostrando a versão antiga).

Para conferir rápido no navegador do Mac, sem gerar o arquivo de 7 MB:

    python3 build.py --dev
    open -a Safari src/dev.html


TAMANHO DA TELA
---------------
O app é desenhado num "palco" fixo de 1242 x 2000 px — a mesma proporção dos
slides do PowerPoint — e depois é reduzido/ampliado por inteiro para caber na
tela do aparelho. Por isso ele preenche o tablet do mesmo jeito que o pptx.

Consequência prática: ao editar posições e tamanhos em "src/app.html", pense
sempre em cima desses 1242 x 2000. Um botão de 52px ali vai aparecer maior ou
menor conforme a tela, mas a proporção entre os elementos nunca muda.


TROCAR UMA FOTO DE CANDIDATO
----------------------------
Substitua o arquivo em src/img/ mantendo o nome (ex.: baba-a.png) e rode o
build. A proporção original é 360 x 410 px.


OS ÍCONES DAS VAGAS
-------------------
São os arquivos src/img/icon-<vaga>.png (icon-baba.png, icon-financeiro.png,
icon-professor.png, icon-gerente.png, icon-recepcionista.png).

Quatro deles foram tirados do próprio "APP CONARH.pptx", então são exatamente
os mesmos da apresentação. O de GERENTE não existia no pptx (lá as vagas eram
porteiro e motorista), então foi desenhado no mesmo traço.

Para trocar: coloque um PNG de 512 x 512 com fundo TRANSPARENTE, traço amarelo
(#FDC500), e rode o build. Qual arquivo cada vaga usa está no src/jobs.json,
no campo "icon".


TROCAR O PIN
------------
Abra src/app.html e procure por:  const ADMIN_PIN = "5288";
Troque 5288 pelo PIN que quiser, salve e rode o build.
